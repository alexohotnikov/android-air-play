# AirPlay для Android TV

Повтор экрана с iPhone и Mac на Android TV, без рекламы, трекеров и лишних сервисов. Телевизор
появляется в **Пункт управления › Повтор экрана** рядом с Apple TV, и картинка с телефона идёт прямо на него.

Домашний прототип, сделанный под Philips 58PUS8507/60 (Android TV 11, MediaTek MT5895). На других
Android TV с Android 8+ и 32-битным ARM, скорее всего, тоже заведётся, но проверено только на нём.

## Что умеет

- **Повтор экрана** iPhone, iPad и Mac со звуком (H.264, AAC-ELD), до 1080p и 60 кадров в секунду.
- **Правильные пропорции**: портретный iPhone показывается с полями по бокам, поворот и открытие фото или
  видео подхватываются на лету.
- **Работает в фоне**: телевизор всегда виден в «Повторе экрана». При подключении экран открывается сам,
  после отключения телевизор возвращается к тому, что было до этого.
- **Экран ожидания** в духе Apple TV: название телевизора и мягко переливающиеся цвета.
- **Настройки** (OK на пульте на экране ожидания): название в «Повторе экрана» и переключатель фонового
  режима.
- **Лёгкий**: в простое около 25 МБ памяти и ноль нагрузки на процессор.

## Чего пока нет

- Звука при трансляции **только музыки** (кодек ALAC: в Android нет декодера). Звук при повторе экрана есть.
- Режима «воспроизвести по ссылке» (HLS): кнопка AirPlay внутри YouTube и других видеоприложений
  с этим телевизором не работает. Включайте **Повтор экрана** — так видео показывается.
- Синхронизации звука и картинки: при повторе экрана незаметно, на длинном видео возможен небольшой сдвиг.
- PIN-кода: подключиться может любой в домашней Wi-Fi.

## Как пользоваться

1. Откройте приложение **AirPlay** на телевизоре один раз.
2. На iPhone: **Пункт управления › Повтор экрана** › выберите телевизор.
3. Чтобы закончить, нажмите **Остановить повтор** на iPhone.

Совет: телевизор на кабеле Ethernet работает стабильнее, чем на Wi-Fi: от iPhone до роутера остаётся
один беспроводной участок вместо двух.

## Сборка

Нужны: JDK 17, Android SDK (платформа 34), NDK `27.2.12479018`, CMake `3.22.1`.

```bash
git clone --recurse-submodules git@github.com:alexohotnikov/android-air-play.git
cd android-air-play
curl -sSL https://github.com/openssl/openssl/releases/download/openssl-3.0.15/openssl-3.0.15.tar.gz \
  | tar xz -C third_party
scripts/build-openssl.sh
JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew --no-daemon assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`.

## Установка на телевизор

Через ADB по сети (на телевизоре: Настройки › Об устройстве › 7 раз «Сборка», затем включить отладку):

```bash
adb connect <ip телевизора>:5555
adb install -r app/build/outputs/apk/release/app-release.apk
# чтобы экран открывался сам при подключении iPhone (на Android TV нет этого пункта в настройках)
adb shell appops set dev.okhotnikov.airplay SYSTEM_ALERT_WINDOW allow
```

После установки выключите отладку по сети обратно: порт 5555 открыт для всей домашней сети.

## Как устроено

Протокол AirPlay — ядро [UxPlay](https://github.com/FDH2/UxPlay) с его встроенным mDNS, собранное через NDK.
Видео декодируется аппаратно (`MediaCodec` прямо в окно), звук идёт через AAudio, без копирования кадров
через Java. Подробности, грабли и принятые решения — в [AGENTS.md](AGENTS.md).
